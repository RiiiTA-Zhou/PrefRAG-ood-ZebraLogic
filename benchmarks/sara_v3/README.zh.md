# SARA v3 — 成文法推理数据集

用于评估 AI 系统**成文法推理（statutory reasoning）**能力的基准。SARA v3 测试将美国联邦税法条文应用于具体事实模式的能力，要求理解条件规则、跨法条引用以及多步数值计算。

## 数据集概览

| 属性 | 数值 |
|----------|-------|
| 总案例数 | 376 |
| 训练集 | 256 |
| 测试集 | 120 |
| 覆盖法条 | 9 个美国《国内收入法典》章节 |
| 问题类型 | 二元蕴含/矛盾判断、数值税务计算 |
| 格式 | Prolog 案例文件 + 纯文本法条 |

## 案例文件格式

每个案例是一个 Prolog 文件，包含四个部分：

```prolog
% Text（文本）
% 对事实情景的自然语言描述。
%
% Question（问题）
% 法律问题及标准答案："Entailment"（蕴含）、"Contradiction"（矛盾）或具体金额。
%
% Facts（事实）
% :- [statutes/prolog/init].
% 编码情景的 Prolog 事实（行为主体、事件、金额、日期）。
%
% Test（测试）
% :- s151_b("Alice","Bob",_,2015).       % 蕴含情况
% :- \+ s151_b("Alice","Bob",2015).      % 矛盾情况
% :- tax("Alice",2017,4931).             % 数值计算情况
% :- halt.
```

### 示例 — 蕴含（法条适用）

```prolog
% Text（文本）
% Alice 和 Bob 自 2015 年 2 月 2 日起结婚。Bob 在 2015 年无收入。
%
% Question（问题）
% Alice 可根据第 151(b) 条为 Bob 获得 2015 年度的免税额。蕴含

% Facts（事实）
:- [statutes/prolog/init].
marriage_(span("married",24,30)).
agent_(span("married",24,30),span("Alice",0,4)).
agent_(span("married",24,30),span("Bob",10,12)).
start_(span("married",24,30),span(20150202,38,47)).

% Test（测试）
:- s151_b("Alice","Bob",_,2015).
:- halt.
```

### 示例 — 矛盾（法条不适用）

```prolog
% Text（文本）
% Alice 和 Bob 自 2015 年 2 月 2 日起结婚。Bob 在 2015 年无收入。
% Alice 和 Bob 为 2015 年合并报税。
%
% Question（问题）
% Alice 可根据第 151(b) 条为 Bob 获得 2015 年度的免税额。矛盾

% Facts（事实）
:- [statutes/prolog/init].
marriage_(span("married",24,30)).
joint_return_(span("jointly",109,115)).
agent_(span("jointly",109,115),span("Alice",78,82)).
agent_(span("jointly",109,115),span("Bob",88,90)).
start_(span("jointly",109,115),span(20150101,121,124)).
agent_(span("married",24,30),span("Alice",0,4)).
agent_(span("married",24,30),span("Bob",10,12)).
start_(span("married",24,30),span(20150202,38,47)).

% Test（测试）
:- \+ s151_b("Alice","Bob",2015).
:- halt.
```

### 示例 — 数值计算

```prolog
% Text（文本）
% Alice 2003 年的收入为 54,313 美元。Alice 和 Bob 自 1985 年 2 月 3 日起结婚。
% Bob 在 2003 年无收入。Bob 和 Alice 为 2003 年合并报税并采用标准扣除额。
%
% Question（问题）
% Alice 在 2003 年需要缴纳多少税？7,611 美元

% Facts（事实）
:- [statutes/prolog/init].
income_(span("income",8,13)).
marriage_(span("married",68,74)).
joint_return_(span("joint return",145,156)).
agent_(span("income",8,13),span("Alice",0,4)).
...

% Test（测试）
:- tax("Alice",2003,7611).
:- halt.
```

## 覆盖的推理类型

| 推理技能 | 示例 |
|---------|------|
| **条件解释** | "如果未提交联合申报表且配偶无总收入……" |
| **跨法条引用** | §151(c) 免税额依赖 §152（被抚养人定义）；§1 税率表依赖 §2（申报身份）和 §7703（婚姻状况） |
| **时间推理** | 结婚日期影响申报身份；2018-2025 年特殊规则与 2018 年前不同 |
| **数值计算** | 应税收入 → 应用标准扣除额 → 应用税率表 → 计算税款 |
| **例外处理** | §3306(b)(1)-(21) 列举了 21 种不属于"工资"的支付类型 |

## 用 SARA v3 测试大语言模型

### 推荐测试方案

1. **选择案例**：使用提供的训练/测试集划分（测试集 = 120 个保留案例）。
2. **准备提示词**：向 LLM 提供相关法条文本和情景描述（来自 `% Text`）。
3. **提问**：提出 `% Question` 中的问题（去掉答案）。
4. **评估**：将 LLM 的回答与标准答案进行比较。

### 提示词模板

```
你是一名法律推理助手。请将以下法条应用于给定事实。

法条 §{章节}：
"{法条文本}"

情景：
{情景描述}

问题：{问题文本}
请仅回答"是"或"否"（或具体金额）。
```

### 评估指标

| 问题类型 | 指标 |
|---------|------|
| 蕴含 / 矛盾 | 准确率、精确率、召回率、F1 |
| 税务计算 | 精确匹配准确率、± 容差 |

### 该基准衡量的能力

- **法条解释能力**：理解层级化条件规则
- **多跳推理**：跨多个法条章节进行推理链连接
- **规则下的算术运算**：根据事实模式计算纳税义务
- **抗记忆化能力**：虚构的人名和新颖的事实组合防止机械记忆
